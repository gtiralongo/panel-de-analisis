- Diseño dashboards interactivos con Streamlit / Plotly Dash / React para monitoreo de carteras

- Automatizo reportes de análisis con generación de PDF/HTML y envío por email/Telegram/Discord
- Diseño UI/UX para interfaces de trading claras y funcionales (Figma, Tailwind, Shadcn/ui)
- Integro APIs financieras (Yahoo Finance, Alpha Vantage, Coingecko, Glassnode)
- Desarrollo sistemas de alertas en tiempo real con WebSockets
- Optimizo código para ejecución de baja latencia en estrategias de alta frecuencia
